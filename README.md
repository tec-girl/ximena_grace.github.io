# Ximena Grace — Belleza profesional

Página de servicios de belleza profesional con acabado de lujo: **pestañas, maquillaje, peinado y depilación**, con agenda de citas en línea.

## Servicios

- **Pestañas** — aplicaciones y retoques.
- **Maquillaje profesional** — social y de ocasión.
- **Peinado** — para eventos y sesiones.
- **Depilación** — servicios de waxing.

## El sitio

- Estático, en HTML, CSS y JavaScript puro, sin compilación.
- Disponible en **seis idiomas**: español, English, français, Deutsch, 中文 y português.
- Diseño en negro, dorado y plateado.

| Archivo | Función |
| --- | --- |
| `index.html` | Página principal y agenda |
| `script.js` | Interactividad y cambio de idioma |
| `style.css` | Estilos |
| `assets/` | Imágenes y recursos |

## Cómo ejecutarlo

Abrir `index.html` en un navegador moderno, o servir la carpeta:

```bash
python3 -m http.server 8000
```
